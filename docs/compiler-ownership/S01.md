# S01: Async state-machine metadata

Resolves [#1892](https://github.com/nickna/SharpTS/issues/1892) by retaining the existing
compilation-local builder ownership and emission ordering. Inventory: `S01-source.txt`
under `artifacts/epic-1865`.

| Stores | Authority and identity |
| --- | --- |
| `Analyzer`, `Functions`, `Analyses`, `SuspensionFreeAwaits` | One compiler's analysis, keyed by qualified function name; await membership uses expression nodes. The function/analysis association is established before declaration. Suspension-free awaits are a separate lowering proof, not emitted fields. |
| `StateMachines`, `StateMachineCounter` | Qualified callable name selects one builder in the free-function route; methods own their builders during method emission. Counter allocates generated names within the compilation. |
| `SuspensionFreePrimitiveFunctions`, `SuspensionFreePrimitiveCores`, `StableSuspensionFreePrimitiveCores` | Same qualified callable identity; narrow typed-core declaration, public Task wrapper and stable direct-call proof are different ABI artifacts/views. The stable map borrows the same core handle, not an independently emitted method. |
| `ArrowBuilders`, `ArrowCounter` | Arrow AST reference identity owns its state-machine builder. Enclosing async callables claim nested arrows before the standalone route; capture-free/synchronous inputs do not require these entries. |
| `ArrowOuterBuilders`, `ArrowParentBuilders` | Same child AST selects either the enclosing function builder or parent arrow builder. Nesting-order declaration ensures the parent exists before a child binds its reference/transitive captures. These aliases intentionally refer to the canonical builders. |
| `ArrowEnclosingClassNames` | Child AST selects the qualified lexical class owner for private accesses; this is independent of the generated state-machine's CLR name. |
| `DeclaredVars`, `UsedAfterAwait`, `DeclaredBeforeAwait` | Reused analysis scratch sets cleared for each arrow. Results are used to declare hoisted fields; they are not persistent ownership catalogs. |
| `CompilationContext.Async` aliases | Borrow the canonical async method and arrow builder maps. Null/absent entries preserve optional availability in ordinary contexts. |

Each [`AsyncStateMachineBuilder`](../../src/SharpTS/Compilation/AsyncStateMachineBuilder.cs)
owns its `TypeBuilder`, core state/builder fields, await-state-number fields, hoisting manager,
MoveNext/SetStateMachine handles, optional receiver/default/lock fields and function DC relay.
Its parameter/local views delegate to the same hoisting manager. Each
[`AsyncArrowStateMachineBuilder`](../../src/SharpTS/Compilation/AsyncArrowStateMachineBuilder.cs)
owns parameter order/fields, local/captured/live capture maps, outer/self/receiver references,
transitive capture membership and stub/MoveNext handles. Source names select slots *inside
that builder*, rather than across different callables. Own function-DC fields and outer DC
relays remain distinct so the two capture paths cannot overwrite one another's metadata.

Declaration precedes stubs/body use, but body emitters legitimately add spill fields and
attach promoted DC references. [`ILCompiler.Async.cs`](../../src/SharpTS/Compilation/ILCompiler.Async.cs)
creates nested types after their bodies; standalone arrow finalization is delayed until its
own MoveNext pass. An early freeze would reproduce the documented late-spill failures.
Builder state describes generated declarations, not the mutable guest state/awaiter values
on each runtime invocation. No process-wide generated-handle cache is involved.

Verification selection `S01` covers nested suspension/relay chains, private class owners,
late spill creation, typed no-suspension cores, duplicate async-arrow declaration absence,
call/apply/bind, saved IL and execution: **494 passed, zero failed/skipped**, recorded in
`S01.log`/TRX. Independent scripts and module name collisions also passed the L02/L03 selections. Existing
unsupported-write rejection expectations remain intact; no production change was required.
