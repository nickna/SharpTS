# F02: Ordinary functions and specialized calls

Resolves [#1888](https://github.com/nickna/SharpTS/issues/1888) by retaining the existing
compiler-local function construction and specialization views. Producer:
[`ILCompiler.Functions.cs`](../../src/SharpTS/Compilation/ILCompiler.Functions.cs).
Inventory: `artifacts/epic-1865/F02-source.txt`.

| Store | Key, writer and consumer contract |
| --- | --- |
| `Builders` | Qualified module/namespace function name selects the declared implementation or suspension stub. Declaration publishes it; bodies/direct callers use it. Namespace aliases intentionally select the same builder. Overload signatures without bodies do not create implementations. |
| `Overloads` | Qualified name owns lower-arity default-parameter forwarding methods. `DefineFunction` creates the list before bodies; overload body emission and direct-call arity selection consume those same builders. Namespace aliases share that list. |
| `MethodOverloads` | Dormant state/context property with no producer or consumer in the source inventory; it is not a competing member authority. Existing class-default emission is separate. |
| `RestParams` | Qualified function name owns `(RestParamIndex, RegularParamCount)`. Declaration establishes rest packing; both ordinary and suspension stubs preserve their runtime parameter marker. Namespace aliases copy this immutable tuple intentionally. |
| `FlattenedNumericRestMethods` | Qualified function/analysis variant index identifies private companions used for specialized body emission. |
| `NumericRestCallMethods` | Exact call AST reference identity selects a proven companion; declaration fills it from stable-binding analysis. Dynamic/reassigned/escaped calls retain the ordinary path. |
| `LiteralNumericRestMethods` | Qualified function/rest arity selects the same companion for guarded literal calls. It is an alternate dispatch index, not another generated implementation. |
| `Lengths`, `Names` | Emitted `MethodBase` identity owns ECMAScript arity and observable name. `MarkFunctionLength`/`MarkFunctionName` populate the map and matching output attribute; reflection consumers read the serialized attribute after compilation. Arity stops at the first default/rest parameter, while optional syntax still counts. |
| `CapturingArguments` | Qualified-name decision from body scanning, registered before direct-call emission. Calls publish untrimmed caller arguments when the target observes `arguments`. |
| `MethodsCapturingArguments` | Builder-identity decision for class/constructor calls; distinct from free-function names. The matching attribute also governs runtime callback dispatch. |

Contexts share these stores by reference. The specialization indexes point to the same
private method; their proof/arity/key roles differ. Missing proof means ordinary dispatch,
not a declaration failure. `arguments` runtime thread state belongs to the call runtime,
not these compile-time sets. Generic declaration authority is now the completed owner in
[F01](F01.md), independently of these name aliases.

Functions/companions are declared before call/body emission; nested/namespace/module
construction remains valid until script phase 9/module phase 11 finalization. Output
attributes and methods are fixed by type finalization. There is no demonstrated duplicate
function authority requiring a broader registry rewrite or new optimization decision.
