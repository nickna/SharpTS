# I03: Fixed catalogs and strategies

Resolves [#1898](https://github.com/nickna/SharpTS/issues/1898) by retaining existing checked
catalog and registration contracts. Inventory: `artifacts/epic-1865/I03-source.txt`.

| Store | Owner, keys and completion |
| --- | --- |
| `FrameworkEmitMetadata` | Static immutable framework-only method handles (double span operations and ordered crypto hash rows). Every declaration comes from a fixed `typeof`/rooted framework delegate; there is no API to register generated handles. Static initialization completes the catalog. |
| `CryptoPrimeEmitConstants`, `ProcessSignalEmitConstants`, `WebCryptoEmitConstants` | Static immutable ordered values: trial primes, signal names/numbers, algorithm name pairs. No generated declarations or mutable guest state are stored. |
| `DatePrototypeEmitCatalog` | Static immutable method-name/arity rows with static selectors. Selectors receive one compilation's Date implementation at use time; they do not capture a generated builder in the process-wide table. |
| `CallHandlerRegistry` | Completed default stateless chain; construction snapshots input membership. Reference identity rejects registering the same handler twice; priority order is stable for ties. Dispatch requires completion, and later/repeated completion writes fail. Handlers resolve generated handles from the supplied context. |
| `TypeEmitterRegistry` | One compiler's instance-TypeInfo-type and ordinal static-name indexes. Checked registration rejects null/duplicate/late writes; default setup completes before contexts. Intentional String/StringLiteral and Iterator/Generator aliases retain one strategy; different compilers own distinct strategies. GlobalThis delegates through its own registry. |
| `BuiltInModuleEmitterRegistry` | One compiler's ordinal specifier-to-strategy index, including explicit aliases and alias-only primitive names. Registration/completion are checked; a missing strategy stays optional. Lookup retains exact strategy identity. |
| Strategy export catalogs | Fixed ordered names in immutable arrays with cached protected list views; HTTPS shares HTTP's immutable catalog. Cluster classification uses an immutable ordinal set. Their selectors look up this compilation's metadata rather than storing it statically. |
| `EmittedBuiltInModuleRegistry` | Per-emitted-module selected `(module, export)` keys own a checked index of family-owned MethodBuilders. Feature selection reserves keys, registration validates same-module and duplicate/selected identity, completion requires all selected declarations. Forward handles are available before bodies/type creation; absent features remain optional misses. |

Construction and selection complete before these registries are exposed to body consumers;
generated callable-index completion is declaration completion, not body/type completion.
There is no setter that promotes a compiler's builder into the fixed framework/value
catalogs. Strategy aliases and export-index handles intentionally reuse their real owner;
the process-wide catalogs and per-compilation emitted catalogs serve different lifetimes.
No additional exception or transfer was needed in the named scope.

Verification selection `I03`: **384 passed, zero failed/skipped**. It exercises mutation
through generic/non-generic interfaces, input snapshots, null/duplicate/missing/late
registration, equal-priority ordering, alias identity, separate registries/compilations,
framework-only metadata, selected-feature completeness, forward builders, script/module

required; current contracts are documented in `ARCHITECTURE.md` and the named sources.
