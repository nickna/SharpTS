# S02: Generator declarations

Resolves [#1893](https://github.com/nickna/SharpTS/issues/1893) by retaining the separate
sync/async generator builders. Immediate inventory: `artifacts/epic-1865/S02-source.txt`.

`GeneratorCompilationState` and `AsyncGeneratorCompilationState` are created with each
compiler. Each owns its analyzer, qualified-function-name-to-AST and -builder maps, and
name counter. The synchronous `StableNativeNumberFunctions` set records a proven numeric
representation; it does not own a second generic generator builder. Method routes use
method AST identity for their DC associations and own a builder during method emission.
Module/namespace context is restored from the callable's definition before emitting bodies.

Each [`GeneratorStateMachineBuilder`](../../src/SharpTS/Compilation/GeneratorStateMachineBuilder.cs)
owns its type, constructor, state/current/sent/executing/injected-completion fields,
receiver/DC/delegation references and iterator/protocol methods. The optional native-number
current field and numeric interface are a separate representation of the same proven
numeric yield stream, while the boxed current remains the ordinary protocol ABI.
Each [`AsyncGeneratorStateMachineBuilder`](../../src/SharpTS/Compilation/AsyncGeneratorStateMachineBuilder.cs)
owns its type/constructor, state/current fields, await task/awaiter/ValueTask-source fields,
receiver/DC/delegation references, return/throw/executing/sent/request-tail fields, protocol
methods and private drive/continuation methods. These declarations support an async request
queue, not the synchronous generator's execution protocol.

Both builders delegate parameter/local field maps to their *own* `HoistingManager`; source
names are scoped to that builder. Contexts borrow its exact handles. State-number fields and
hoisted slot names are construction keys, not cross-compilation caches. Missing receiver,
DC, delegation or native-number fields are intentional for inputs that need none. Outer
captured variables stay on their enclosing live storage instead of being copied into a
hoisted local map.

[`ILCompiler.Generators.cs`](../../src/SharpTS/Compilation/ILCompiler.Generators.cs) and
[`ILCompiler.AsyncGenerators.cs`](../../src/SharpTS/Compilation/ILCompiler.AsyncGenerators.cs)
declare the machine/protocol and public stub before calls or body emission, then attach DC
references, emit stubs and MoveNext bodies, and call `CreateType`. Body emission can declare
spill/temporary fields, so pre-body completion is unsound. Runtime calls create new machine
objects; metadata completion does not freeze their state or shared mutable lexical storage.
The two state maps and typed/boxed views are distinct artifacts, not conflicting ownership.

Verification selections `S02` and `S02-methods` exercise sync/async yields, live captures,
delegation, finally/injected return/throw, pending suspension, receiver identity, numeric
iteration, nested callables and lifetime. Execution assertions accompany saved-IL checks
where existing tests provide them; logs/TRX are under `artifacts/epic-1865`. No production
change was required. `S02`: **836 passed**; `S02-methods`: **74 passed**; zero failed/skipped.
Cross-module suspended-body isolation also passed in L02's module selection.
