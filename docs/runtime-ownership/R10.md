# R10 — Filesystem

Outcome for [#1877](https://github.com/nickna/SharpTS/issues/1877): all four roots have
verified ownership. Descriptor tables, stream instances and watcher registries are
intentionally retained runtime state. No specific ownership action is deferred.
The [shared conventions](README.md) apply.

All four owners are optional under UsesFs and belong to one output. Forward method
and type declarations precede dependent callback/stream bodies and finalization;
EmitAll completes them after all generated types. Non-null construction replacement
is allowed by the setters until completion. Guest mutation/lifetime is independent.

Canonical selection/order is in [EmitAll](../../src/SharpTS/Compilation/RuntimeEmitter.cs).
Filesystem emitters pass operation, stream and watcher construction fields/helpers
as local records; module export consumers index the same family-owned declarations
through BuiltInModules. BCL File/Stream/FileSystemWatcher handles are borrowed framework
metadata and do not become emitted owners. The test classes verify feature absence,
implied/present/full selection, hosted/ordinary saved IL and actual generated execution.

This is bounded ownership evidence, not a platform-wide symlink/permission audit or
complete Node filesystem compatibility. The prior duplicate lstat repair is credited
in S08 of the [reconciliation](../plans/archive/1599-historical-reconciliation.md).
