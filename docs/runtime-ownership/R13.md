# R13 — Cryptography

Outcome for [#1880](https://github.com/nickna/SharpTS/issues/1880): both roots have
verified ownership. Active crypto instances, singleton wrappers and scoped construction
handles are intentionally retained. No specific ownership action is deferred.
The [shared conventions](README.md) apply.

[EmitAll](../../src/SharpTS/Compilation/RuntimeEmitter.cs) selects both families and
passes canonical Crypto/WebCrypto metadata to module factories and bound-method
construction. BCL algorithm/key/certificate MethodInfo references and temporary
helper builders are local inputs. Consumer metadata tokens reference generated
declarations, preserving ordinary output's lack of a SharpTS reference. Existing
declaration-time replacement is retained where setters support it; completion freezes
metadata while ongoing algorithm state remains mutable.

The focused tests provide lifecycle, saved-output and active-operation evidence.
This is an ownership verification, not an algorithm/security assessment or exhaustive
WebCrypto compatibility audit. The earlier X509 issued-check correction retains its
precise verified decision in S11 of the
[historical reconciliation](../plans/archive/1599-historical-reconciliation.md).
