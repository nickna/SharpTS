The named source files define each handle's mutation policy. StringCoercion,
BoxedPrimitives, NumericCoercion, Templates, Math, BigInt, Booleans, Symbols, Numbers,
Dates and NodeErrors allow non-null handle replacement during declaration; the other
root setters reject duplicates. Completion freezes all writers. This is retained construction behavior,
not evidence of immutable guest objects. Nested implementation validation preserves
repairable parent completion. Producer order is
[EmitAll](../../src/SharpTS/Compilation/RuntimeEmitter.cs) and
[runtime-class emission](../../src/SharpTS/Compilation/RuntimeEmitter.RuntimeClass.cs).
Static/property/operator consumers use canonical owners or explicit optional inputs;
local formatter, prototype, error and regex construction records borrow these handles.

Saved-output reuse tests execute these helpers and verify dependencies in hosted and
ordinary output. Full language compatibility is outside this ownership result. In
particular, the historical boxed Number and computed tagged-template receiver defects
retain B16/B15's linked destinations in the
[reconciliation](../plans/archive/1599-historical-reconciliation.md); no repair is claimed.
