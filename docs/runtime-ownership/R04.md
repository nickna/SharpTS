# R04 — JSON and specialized representations

Outcome for [#1871](https://github.com/nickna/SharpTS/issues/1871): all four roots have
verified ownership. Late Program shape declaration, shared fingerprint identity and
mutable guest materialization are intentionally retained. No specific ownership action
is deferred. The [shared conventions](README.md) apply.

| Root / source | Availability and declaration → completion | Retained mutation/aliases and evidence |
| --- | --- | --- |
| [Json](../../src/SharpTS/Compilation/EmittedJsonRuntime.cs) | Required namespace singleton/populate shell; nested `EmittedJsonImplementation` exists only under UsesJSON (also selected for HTTP). Parse/stringify/helpers are emitted before root completion in EmitAll. | Facade and implementation permit non-null handle replacement while declaring, then freeze. Guest namespace and serializer stores are output-local and mutable. `EmittedJsonRuntimeTests` checks independent masks, absent shells, HTTP detection and present/minimal/present reuse with real parse/stringify. |
| [Records](../../src/SharpTS/Compilation/EmittedRecordStorageRuntime.cs) | Required marker interface; optional nested `EmittedScalarRecordRuntime` and layout registries selected from scalar/compact shape inventories. Early record types precede runtime helpers; EmitAll validates exact expected key/arity coverage before freezing child/root. | Read-only live views expose canonical type/ctor/field handles. Inline slots share by arity; typed/compact slots share by ordinal fingerprint. | [UnionValues](../../src/SharpTS/Compilation/EmittedUnionRuntime.cs) | Required marker interface and Value getter; emitted/created and completed early in EmitAll. | Baked Type/MethodInfo are canonical; local builders do not survive as a second owner. `EmittedUnionRuntimeTests` executes typeof/value unwrapping, staged reads, rejected duplicates and saved-output identity. |

[JSON emission](../../src/SharpTS/Compilation/RuntimeEmitter.Json.Stringify.cs) passes helper
builders in construction-local records rather than retaining them on the reusable
emitter. Record construction registers with `Records`; JSON codegen registers late
fields with `JsonShapes`; union consumers read `UnionValues`. These are different
lifetimes, so completing JsonShapes at the runtime boundary would be incorrect.
Object-descriptor consumers borrow the namespace/implementation explicitly, covered
by `EmittedObjectDescriptorRuntimeTests` with opposite global selection.

The test reuse cases save, IL-verify and execute generated JSON/record/union helpers
and check prior output stores after later emissions. This supports the specific
metadata and materialization contracts, not all JSON compatibility or every possible
shape optimization. The earlier JSON leakage observation's repair remains credited
in S01 of the [historical reconciliation](../plans/archive/1599-historical-reconciliation.md).
