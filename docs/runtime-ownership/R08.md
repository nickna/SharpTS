# R08 — Scheduling, cancellation and async context

Outcome for [#1875](https://github.com/nickna/SharpTS/issues/1875): all eight roots have
verified ownership. Output-local queues, host hooks and ambient guest context are
intentionally retained. The [shared conventions](README.md) apply.

| Root / source | Availability and declaration → completion | Retained state and execution evidence |
| --- | --- | --- |
| [Cancellation](../../src/SharpTS/Compilation/EmittedCancellationRuntime.cs) | Required public flag/check/factory declarations precede drain consumers; independent check and exception-body markers required at runtime-class completion. | Flag is mutable per assembly. `EmittedCancellationRuntimeTests` executes Run/WaitForTask/PumpOnce cancellation, distant timers and volatile guest polls. |
| [Promise](../../src/SharpTS/Compilation/EmittedPromiseRuntime.cs) | Optional UsesPromise, implied by dependent features and hosted mode. | [Timers](../../src/SharpTS/Compilation/EmittedTimerRuntime.cs) | Required timeout/virtual-timer types and queue helpers; early type handles precede methods, completed after bodies in EmitAll. | Virtual queue, cancellation/ref bits and timeout payloads belong to generated output/guest instances. Timer lifecycle tests validate all handles; the added reuse regression retains earlier pending timers across later emissions and cancels each queue independently. |
| [Microtasks](../../src/SharpTS/Compilation/EmittedMicrotaskRuntime.cs) | Required QueuePromiseJob forward declaration before Promise bodies; drain declared before enqueue body; completed at EmitAll end. | Shared FIFO queue is per output. | [AsyncLocalStorage](../../src/SharpTS/Compilation/EmittedAsyncLocalStorageRuntime.cs) | Optional UsesAsyncLocalStorage; created class/ctor is readable before final family completion. | BCL AsyncLocal and saved context belong to generated instances. `EmittedAsyncLocalStorageRuntimeTests` executes restoration after returns/errors/invalid callbacks and emitter reuse. |
| [Abort](../../src/SharpTS/Compilation/EmittedAbortRuntime.cs) | Optional UsesAbortController (including implied availability). Early namespace/event/helpers precede late population; completed at EmitAll end. AbortSignal.any selection records its precise deployment requirement. | Signal/token/listener state is guest state; tests execute cancellation/wrappers, earlier reuse and explicit any selection independent of coarse flags. |

The producers are [EmitAll](../../src/SharpTS/Compilation/RuntimeEmitter.cs),
[timer emission](../../src/SharpTS/Compilation/RuntimeEmitter.Timer.cs) and
[timer Promise emission](../../src/SharpTS/Compilation/RuntimeEmitter.TimerPromises.cs).
Closure builders and timer callback fields remain emission-local construction inputs;
captured handles refer to the same output's components. Core scheduling setters permit
non-null replacement during declaration; completion seals metadata. Queue/ambient
mutation is a separate runtime contract. Tests reject component replacement and
late optional/hosted selection.

Focused inspection found missing direct execution proof for pending timer/microtask
state surviving reuse. `ReusedEmitterKeepsEarlierTimerQueuesJobsAndPromiseClosuresIndependent`
now covers selected/minimal/selected outputs in hosted and ordinary modes, verifies
saved IL/dependencies, and executes earlier queues/closures after all emissions.
No production change was needed. No specific ownership action remains deferred.
Historical arbitrary-load behavior retains B14's destination in the
[reconciliation](../plans/archive/1599-historical-reconciliation.md).
