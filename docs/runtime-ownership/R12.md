# R12 — Binary storage and atomics

Outcome for [#1879](https://github.com/nickna/SharpTS/issues/1879): all six roots have
verified ownership. Backing-store aliases, immutable registry views and construction
handles are intentionally retained. No specific ownership action is deferred.
The [shared conventions](README.md) apply.

| Root / source | Availability and declaration → completion | Retained state and evidence |
| --- | --- | --- |
| [ArrayBuffer](../../src/SharpTS/Compilation/EmittedArrayBufferRuntime.cs) | Optional under HasAnyTypedArray; type/storage/slice/detach forward declarations precede bodies and EmitAll completion. | Backing byte array and detach state are guest-instance data. Tests execute owned slice/detach/storage, absence/implied selection and saved consumers. |
| [SharedArrayBuffer](../../src/SharpTS/Compilation/EmittedSharedArrayBufferRuntime.cs) | Optional under the same conservative typed-array gate; declared before view consumers and completed after bodies. | Views/clones intentionally share backing storage; slice copies. Tests execute those alias rules with atomics in standalone output and direct saved storage helpers. |
| [DataView](../../src/SharpTS/Compilation/EmittedDataViewRuntime.cs) | Optional HasAnyTypedArray; fields/ctors/adapters support forward calls, bodies/types finish before completion. | View offset/length/backing aliases stay per guest instance. Tests execute ordinary/shared backing, bounds, extracted endian adapters and Reflect construction/coercions standalone. |
| [TypedArrays](../../src/SharpTS/Compilation/EmittedTypedArrayRuntime.cs) | Required IsTypedArray detection; nested `EmittedTypedArrayImplementation` only for HasAnyTypedArray. Constructor/unboxed/from-object/from-buffer registries declare before consumer bodies; exact key sets required at completion. | Registries expose read-only canonical handles, reject unknown/null/duplicate entries and freeze. Instance backing/view/copy and bound method fields retain guest identity. Tests execute numeric/BigInt kinds, bulk/clamp/clone and unboxed helpers; annotation-only paths prove absent-implementation fallback. |
| [Buffer](../../src/SharpTS/Compilation/EmittedBufferRuntime.cs) | Optional UsesBuffer. HasTypedArrayCopy snapshots HasAnyTypedArray at creation; unavailable copy reads/writes fail without preventing other declarations completing. Type/ctors/conversion helpers precede consumers and completion. | Buffer bytes are guest state; optional typed-array copy borrows canonical storage. Buffer tests check gates, forward calls, global getter and saved consumers; text-encoding tests execute Buffer-related encoding. |
| [Atomics](../../src/SharpTS/Compilation/EmittedAtomicsRuntime.cs) | Optional under HasAnyTypedArray, retaining the existing gate rather than requiring a direct Atomics use. Local validation/throw/load-store helpers precede operation bodies and completion. | Atomic backing storage remains shared guest state; local helper metadata does not survive on RuntimeEmitter. Tests execute saved operations/errors/current wait semantics, exact throw bodies and earlier backing state after reuse. |

Selection/order is in [EmitAll](../../src/SharpTS/Compilation/RuntimeEmitter.cs).
View, Buffer, invocation and object property consumers use these owners or supplied
optional implementation inputs. Local type/field/read-write helper builders borrow
the same module's metadata. Declaration-time handle replacement follows each source
setter's existing policy; registry registrations are single assignment, and completed
metadata rejects later writes. Completion does not detach/copy/freeze guest buffers.

The tests cover hosted/ordinary feature absence/presence, saved IL and actual storage,
adapter, atomic and standalone view execution. This disposition does not claim full
Atomics wait/wakeup compatibility or an exhaustive cross-thread memory-model audit.
