# R07 — Arrays and collections

Outcome for [#1874](https://github.com/nickna/SharpTS/issues/1874): all nine roots have
verified ownership. Guest storage, weak-table semantics and declaration-time replacement
are intentionally retained. No specific ownership action is deferred.
The [shared conventions](README.md) apply.

Producers follow [EmitAll](../../src/SharpTS/Compilation/RuntimeEmitter.cs); array,
collection and generic property consumers read canonical components. Local queue,
iterator and bound-method construction builders have one emission's lifetime.
Declaration-time non-null replacement remains where setters permit it; completed
metadata rejects writers, while guest arrays/collections stay mutable. Tests assert
explicit boundaries and absence of flat duplicate aliases. Saved output is IL-verified
and executed, with hosted/ordinary reuse and standalone array cases.

The historical Map.groupBy key-alias observation is separately reconciled in
[#1911](https://github.com/nickna/SharpTS/issues/1911) / [#1929](https://github.com/nickna/SharpTS/pull/1929).
This ownership result adds no semantic repair or guarantee about GC callback timing.
