# R05 — Runtime roots, modules and deployment

Outcome for [#1872](https://github.com/nickna/SharpTS/issues/1872): all thirteen roots
have verified ownership. Configuration references, late compiler registries and
output-local guest registries are intentionally retained. No specific ownership action
is deferred. The [shared conventions](README.md) apply.

| Root / source | Availability, declaration and completion | Mutation/aliases and applicable evidence |
| --- | --- | --- |
| [Deployment](../../src/SharpTS/Compilation/EmittedDeploymentRequirements.cs) | Required, empty-capable. Runtime and guest call sites contribute; ILCompiler completes only after guest emission in script/module paths. | Immutable ordinal reason snapshots coalesce repeats; capability flags accumulate and always imply RuntimeAssembly. Invalid flags/reasons publish nothing. `EmittedDeploymentRequirementsTests` verifies late recording, all masks and reuse. |
| [RegexLiteralCache](../../src/SharpTS/Compilation/EmittedRegexLiteralCacheRuntime.cs) | Required registry; compiler begins with selected sites and completes all fields before guest bodies, including empty selection. | Site keys use AST reference identity, not value equality. Generated Program fields lazily cache guest Regex values; failed construction leaves them empty. `EmittedRegexLiteralCacheRuntimeTests` verifies phase, identity and failure retry across compilation paths. |
| [Sentinels](../../src/SharpTS/Compilation/EmittedSentinelRuntime.cs) | Required. Undefined is created/readable before lexical sentinel declaration; both complete early in EmitAll. | Sentinel identity belongs to each output. `EmittedSentinelRuntimeTests` checks early reads, saved values and distinct assemblies. |
| [Namespaces](../../src/SharpTS/Compilation/EmittedNamespaceRuntime.cs) | Required. Type and constructor are emitted/created and completed before namespace consumers. | Namespace values are guest instances. `EmittedNamespaceRuntimeTests` executes isolated helper construction and reuse without other owners. |
| [ClassInitialization](../../src/SharpTS/Compilation/EmittedClassInitializationRuntime.cs) | Required method shell; body marker required before runtime-class completion. | No second class initializer owner; unwrapped exception identity is retained. `EmittedClassInitializationRuntimeTests` executes initialization and original exception identity. |
| [RuntimeClass](../../src/SharpTS/Compilation/EmittedRuntimeClass.cs) | Required $Runtime type declared once in phase one, readable for deferred body emission, finalized at the end of EmitAll. Completion requires IsCreated. | Borrowed type builder is canonical through finalization; it is not replaced by another output's type. `EmittedRuntimeClassTests` checks phase-one openness and deferred/optional families across reuse. |
| [BuiltInStatics](../../src/SharpTS/Compilation/EmittedBuiltInStaticDispatchRuntime.cs) | Required forward lookup shell; body marker precedes runtime-class completion. | Explicit peers supply optional families. `EmittedBuiltInStaticDispatchRuntimeTests` executes name/arity/identity lookup and opposite selection. |
| [GlobalObject](../../src/SharpTS/Compilation/EmittedGlobalObjectRuntime.cs) | Required two-stage owner: phase one seals declarations; initializer and late indirect-eval method precede final completion in GlobalThis emission. | Singleton/guest properties stay output-local and mutable; HasSingletonField is an intentional nullable probe. `EmittedGlobalObjectRuntimeTests` checks all stages and global identity after reuse. |
| [EventSubscriptions](../../src/SharpTS/Compilation/EmittedEventSubscriptionRuntime.cs) | Required registry/helpers emitted and completed in runtime-class pass. | .NET subscription entries belong to generated output state; local subscription construction borrows exact metadata. `EmittedEventSubscriptionRuntimeTests` executes registry behavior and deployment/reuse. |
| [ResourceDisposal](../../src/SharpTS/Compilation/EmittedResourceDisposalRuntime.cs) | Required disposal method declared/emitted then completed in runtime-class pass. | Lookup/invocation inputs borrow canonical peers; disposable values belong to guest code. `EmittedResourceDisposalRuntimeTests` executes injected dispatch and actual disposal. |
| [Enums](../../src/SharpTS/Compilation/EmittedEnumRuntime.cs) | Required reverse-lookup method body precedes runtime-class completion. | Enum dictionary contents remain guest data; `EmittedEnumRuntimeTests` executes saved lookup and output identity. |
| [Modules](../../src/SharpTS/Compilation/EmittedModuleRuntime.cs) | Required registry/init/register; nested CommonJs under UsesCjsRequire and DynamicImport under UsesDynamicImport. CommonJs forward declarations precede later registry bodies. EmitAll validates both children before freezing either. | `EmittedCommonJsRuntime`/`EmittedDynamicImportRuntime` own selected handles; declaration-time replacement is allowed, then frozen. Export write-through/module tables stay per output. `EmittedModuleRuntimeTests` checks independent selection, repair, precompleted child and saved CommonJS execution. |
| [BuiltInModules](../../src/SharpTS/Compilation/EmittedBuiltInModuleRegistry.cs) | Required export index begins with a snapshot of selected keys at EmitAll entry; family methods register before completion at exit. Reads permit forward references before bodies/types finish. | Index borrows family-owned handles, requires current module and one assignment per key; intentional aliases may share a method. `EmittedBuiltInModuleRegistryTests` checks every selected export, selection snapshot and previous exports after reuse. |

The canonical producer ordering is in
[EmitAll](../../src/SharpTS/Compilation/RuntimeEmitter.cs),
[runtime-class phase one](../../src/SharpTS/Compilation/RuntimeEmitter.RuntimeClassPhase1.cs),
[runtime-class bodies](../../src/SharpTS/Compilation/RuntimeEmitter.RuntimeClass.cs)
and [ILCompiler finalization](../../src/SharpTS/Compilation/ILCompiler.cs).
Compiler and built-in emitters consume these owners, not replacement flat indexes.
Framework references and local helper/type builders remain scoped construction inputs.

The saved-output tests execute global/module/resource/enum behavior and verify IL and
dependency references in hosted and ordinary paths. No broad module conformance claim
is made: historical module-name collisions remain at B11's linked destination in the
[reconciliation](../plans/archive/1599-historical-reconciliation.md).
