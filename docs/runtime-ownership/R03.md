# R03 — Objects, descriptors and property access

Outcome for [#1870](https://github.com/nickna/SharpTS/issues/1870): all seventeen roots
have verified ownership. Mutable guest stores and the declaration-time replacement
policies below are intentionally retained. No concrete ownership action remains deferred.
The [shared conventions](README.md) apply.

Except Proxy factories, every root is a required per-output child. Handles are readable
once declared; `EmitAll` completes these owners after runtime-class bodies/finalization.
Setters are single assignment except Reflect capability handles and SymbolAccessors,
whose non-null replacement is allowed until completion.

[Runtime-class emission](../../src/SharpTS/Compilation/RuntimeEmitter.RuntimeClass.cs)
orchestrates the early shells and bodies;
[EmitAll](../../src/SharpTS/Compilation/RuntimeEmitter.cs) seals the owners.
Property emitters and Object/Reflect static consumers use these canonical components.
Local helper records borrow peers; support-type/field builders and BCL handles are
construction state within the emitting pass. Boundary tests reject removed aliases
and aggregate captures.

Historical semantic defects retain their explicit destinations in the
[historical reconciliation](../plans/archive/1599-historical-reconciliation.md),
including B01's non-writable descriptor assignment. No general descriptor conformance
repair is claimed. Saved-output execution and reuse support the listed contracts.
