# R09 — Process, host APIs and text utilities

Outcome for [#1876](https://github.com/nickna/SharpTS/issues/1876): all twelve roots
have verified ownership. Output-local host state and explicit late-bound runtime
dependencies are intentionally retained. No specific ownership action is deferred.
The [shared conventions](README.md) apply.

All owners are per compilation. Required and selected optional declarations support
forward reads; bodies/type finalization precede EmitAll completion. Non-null handle
replacement during declaration is permitted where the owner setters support it;
completion freezes every writer. Optional owners use checked Require accessors.

[EmitAll](../../src/SharpTS/Compilation/RuntimeEmitter.cs) owns selection and seals
the family owners; built-in module registration borrows these family declarations.
Process/stream/readline/text construction records and helper builders remain local
to their emission. Consumers use the matching canonical owner and BCL references
resolved by the type provider. The test suites check feature absence/presence, staging,
hosted/ordinary saved IL, actual helper execution and prior-output reuse.

This disposition preserves current compiled behavior; it does not assert platform-wide
process/TTY/OS compatibility, every child-process lifecycle or general Intl conformance.
