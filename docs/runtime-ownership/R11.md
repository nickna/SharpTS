# R11 — Networking and fetch

Outcome for [#1878](https://github.com/nickna/SharpTS/issues/1878): all six roots have
verified ownership. Network-instance state, output-local caches and scoped construction
records are intentionally retained. No specific ownership action is deferred.
The [shared conventions](README.md) apply.

[EmitAll](../../src/SharpTS/Compilation/RuntimeEmitter.cs) supplies the canonical
components to networking emitters, then completes them. Module exports index the same
methods; local BCL HttpClient/socket/stream/certificate handles remain borrowed framework
metadata. Local construction helpers preserve phase ordering without competing owners.
Selected metadata supports forward reads; missing/late writes fail. Single-assignment
policies apply to Fetch/TLS/Dgram/DNS; Http/Net retain the replacement policy in their setters.
