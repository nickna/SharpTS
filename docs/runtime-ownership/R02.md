# R02 — Iterator and generator protocols

Outcome for [#1869](https://github.com/nickna/SharpTS/issues/1869): all eight roots
have verified ownership. Iterator-instance state and captured `next` identity are
intentionally retained. No specific ownership defect or missing-proof action remains.
The [shared conventions](README.md) apply.

| Root / source | Availability and declaration → body → completion | Retained lifetime and execution evidence |
| --- | --- | --- |
| [IteratorHelpers](../../src/SharpTS/Compilation/EmittedIteratorHelpersRuntime.cs) | Required. Adapter constructors and helper methods are emitted in the runtime-class pass, then completed there. | Adapter enumerator/callback fields belong to each iterator instance; local construction handles stay within emission. `EmittedIteratorHelpersRuntimeTests` executes lazy callbacks, supplied invocation/truthiness and reuse. |
| [IteratorCollection](../../src/SharpTS/Compilation/EmittedIteratorCollectionRuntime.cs) | Required. `ToList`/`IntoList` are forward-declared before their mutually dependent bodies; runtime-class completion requires both. | Caller-owned destination lists intentionally mutate. `EmittedIteratorCollectionRuntimeTests` emits a caller before bodies and checks supplied mutation/Buffer selection and saved-output collection behavior. |
| [IteratorProtocol](../../src/SharpTS/Compilation/EmittedIteratorProtocolRuntime.cs) | Required. Lookup/next/result/close/call declarations precede runtime-class completion. | Compact-result reads use explicit shape/descriptor inputs, rather than competing stores. `EmittedIteratorProtocolRuntimeTests` executes result and close behavior and both compact-reader selections. |
| [IteratorWrappers](../../src/SharpTS/Compilation/EmittedIteratorWrapperRuntime.cs) | Required. Type/constructor/sent-value method are emitted and created before runtime-class completion. | Wrapper fields retain the iterator and captured next record for the instance lifetime; `EmittedIteratorWrapperRuntimeTests` checks captured-next identity, sent values, invalid results and saved ABI. |
| [IteratorRecords](../../src/SharpTS/Compilation/EmittedIteratorRecordRuntime.cs) | Required. Next lookup and zero/sent argument invocation helpers are emitted and completed in `RuntimeEmitter.Iterator`. | A record intentionally captures the original next method. `EmittedIteratorRecordRuntimeTests` executes validation and reuse; exact-input tests exclude redundant aggregate/store aliases. |
| [AsyncGenerators](../../src/SharpTS/Compilation/EmittedAsyncGeneratorRuntime.cs) | Optional when `UsesAsyncGenerator` or `UsesForAwaitOf`. Interface is declared early. Continuations are selected by `UsesAsyncGenerator`, `FromSync` by `UsesForAwaitOf`; each child completes before root completion. | Nested `EmittedAsyncGeneratorContinuationRuntime` owns its two methods; `EmittedAsyncFromSyncRuntime` owns constructor/adaptation/result/await helpers. Child availability and repairable root completion are independent. `EmittedAsyncGeneratorRuntimeTests` verifies all gates and executes adapter/continuation output. |
| [Generators](../../src/SharpTS/Compilation/EmittedGeneratorRuntime.cs) | Required synchronous and numeric interfaces. Created and completed early in `EmitAll` for later generator consumers. | Interface handles belong to this output, not a shared generated type. `EmittedGeneratorProtocolRuntimeTests` checks saved signatures, identity and reuse. |
| [StableIteratorResults](../../src/SharpTS/Compilation/EmittedStableIteratorResultRuntime.cs) | Optional for nonempty `CompactObjectRecordStableIteratorShapes`. Emission creates the value type, records baked type/constructor/field metadata, then completes before generator consumers. | Replacing builder construction with baked reflection members is intentional; no second metadata index. `EmittedGeneratorProtocolRuntimeTests` executes the constructor and checks fields, negative zero, absence/presence and independent completion. |

Producers are [EmitAll](../../src/SharpTS/Compilation/RuntimeEmitter.cs),
[runtime-class emission](../../src/SharpTS/Compilation/RuntimeEmitter.RuntimeClass.cs)
and [iterator emission](../../src/SharpTS/Compilation/RuntimeEmitter.Iterator.cs).
Consumers use the matching `Iterator*` owners or explicit peer inputs. Local adapter
type/method/field builders and BCL enumerator references have one emission's lifetime;
the tests assert that scoped helpers retain neither the aggregate runtime nor feature flags.
All selected owners reject null/duplicate declarations and later mutation.

The following classes passed **99/99 tests**, zero skips/failures; reuse cases save,
IL-verify, load and execute both hosted and ordinary assemblies:

- [EmittedAsyncGeneratorRuntimeTests](../../tests/SharpTS.Tests/CompilerTests/EmittedAsyncGeneratorRuntimeTests.cs)

- [EmittedIteratorHelpersRuntimeTests](../../tests/SharpTS.Tests/CompilerTests/EmittedIteratorHelpersRuntimeTests.cs)

- [EmittedIteratorWrapperRuntimeTests](../../tests/SharpTS.Tests/CompilerTests/EmittedIteratorWrapperRuntimeTests.cs)

Generator protocol ownership does not certify arbitrary-load generator scheduling or
allocation behavior. The historical generator-load observation already has destination
[#1913](https://github.com/nickna/SharpTS/issues/1913), reconciled in
[#1943](https://github.com/nickna/SharpTS/pull/1943); this report claims no new repair of it.
